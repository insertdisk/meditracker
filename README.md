**Meditracker** is a web-based medicine inventory management system designed to help users organize and monitor medicine stocks. It allows administrators to manage medicine records, track quantities, and monitor expiration dates through a simple user interface.

## Features

- Admin login
- View medicine inventory
- Add, edit, and delete medicine records
- Search for medicines
- Low-stock indicators
- Medicine expiration date tracking

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- MAMP

## Installation and Setup

1. Clone this repository:
   ```bash
   git clone https://github.com/insertdisk/meditracker.git
   ```
2. Move the project folder into your MAMP `htdocs` directory.
3. Start Apache and MySQL in MAMP.
4. Create a MySQL database named `medilog`.
5. Configure `db_connection.php` with your local database credentials.
6. Open the project in your browser:

   `http://localhost:8888/meditracker/`

## Database

Meditracker uses MySQL to store:
- Administrator accounts
- Medicine names and identification details
- Quantities and storage locations
- Expiration dates and remarks
